# 🌸 향수 추천 (Perfume Recommender)

노트(탑/미들/라스트)·가격·계절·상황·성별·예산으로 향수를 **탐색·비교·추천**하는
빌드리스 정적 **싱글 페이지 웹앱**. 추천은 설명 가능한 **규칙 기반 매칭 엔진**으로 동작합니다.

**English: [README.md](./README.md)**

**라이브 데모: https://clsoftlab-lang.github.io/perfume-recommender/**

---

## 무엇인가요

가상의 향수 카탈로그를 탐색하고, 인라인 SVG **노트 피라미드**와 지속력·확산력 게이지가
있는 상세 페이지를 열고, 짧은 **설문**으로 *이유가 붙은* 순위 추천을 받고, 특정 향료로
검색하고, 최대 4개를 나란히 **비교**할 수 있습니다. 전부 브라우저에서만 동작합니다.

## 매칭 엔진 원리

각 향수를 설문 응답에 대해 **0~100점**으로 채점합니다. 총점은 5개 차원의 가중 합이며
가중치 합은 항상 100입니다. 응답하지 않은 차원은 **중립**으로 처리해 만점을 부여하므로,
질문을 건너뛰어도 순위가 왜곡되지 않습니다.

| 차원 | 가중치 | 규칙 |
|------|:-----:|------|
| 노트 계열 | **40** | `40 × (일치한 선호 계열 ÷ 선택한 계열 수)` |
| 계절 | **20** | 선택 계절이 향수에 맞으면 만점, 아니면 0 |
| 상황 | **20** | 선택 상황이 향수에 맞으면 만점, 아니면 0 |
| 예산 | **15** | 예산 이내면 만점, 초과 시 선형 감점 `15 × max(0, 1 − (가격−예산)/예산)` |
| 성별 | **5** | 유니섹스이거나 타겟 일치 시 만점, 아니면 0 |

동점은 사용자 평점으로 정렬합니다. 각 추천 결과에는 점수를 만든 **이유**가 사람이 읽을 수
있는 문구로 함께 표시됩니다(예: "선호 계열 우디 일치", "예산 이내").
로직은 [`recommender.js`](./recommender.js)에 있으며, 앱과 테스트가 동일한 순수 모듈을 씁니다.

- **노트 피라미드** (`svg.js` → `notePyramid`): 위(탑)가 좁고 아래(라스트)가 넓은 3단
  사다리꼴 SVG. 각 단에 향료 라벨. 순수 인라인 SVG(바이너리 없음), 다크 모드 대응.
- **가격 비교**: 향수마다 여러 판매처(mock) 가격을 가지며, 상세에서 정렬 후 최저가를 태그.
  비교표는 행마다 최적값(최저 가격, 최고 평점·지속력·확산력)을 강조.
- **비슷한 향수** (`similarTo`): 유사도 = 계열 Jaccard(0.5) + 전체 노트 Jaccard(0.35) +
  계절·상황 Jaccard(0.15).

## 기능

- **향수 탐색** — 계열/계절/상황/성별·가격 필터, 검색, 정렬
- **향수 상세** — 노트 피라미드, 지속력·확산력 바, 가격 비교(mock), 태그, 리뷰, 비슷한 향수
- **향 추천 설문** → 매칭 점수 링과 이유가 붙은 순위 추천
- **노트로 찾기** — 특정 향료가 포함된 향수 모두 찾기
- **찜·비교** — 위시리스트, 최대 4개 비교표(행별 최적값 강조)
- **부가 기능** — 계절/상황 태그, 입문/시그니처/가성비 배지, 가성비 점수, 라이트/다크 테마, 원클릭 초기화

## 로컬 실행

빌드·의존성 없음. ES 모듈과 `fetch` 때문에 HTTP로 서빙해야 합니다:

```bash
python -m http.server 8986
# http://localhost:8986 접속
```

검증 실행(JSON 파싱, JS 구문, index 컨테이너, 추천 엔진 단위 테스트):

```bash
node check.mjs
```

## 데모 모드 경계

**본 프로젝트는 데모 빌드입니다. 구체적으로:**

- **모든 향수·브랜드·가격은 가상**입니다 — 일반 향료명, 가상 브랜드, 실제 제품 데이터 없음.
- **추천은 규칙 기반 매칭**이며, 머신러닝이나 전문 조향 자문이 아닙니다.
- **가격은 mock** 예시값이며 실시간 판매 데이터가 아닙니다.
- **localStorage는 실 DB가 아닙니다** — 설문·찜·비교는 브라우저에만 저장되며 초기화 버튼으로 언제든 삭제됩니다.
- **실 계정·로그인·PII 없음** — 어떤 개인정보도 수집·전송하지 않습니다.
- 실제 서비스라면 실 카탈로그, 실시간 가격 피드, 계정, 서버 영속화가 추가됩니다.

## 기술

프레임워크·번들러 없이 순수 HTML + CSS + ES 모듈 JS. 모든 경로는 상대경로라 GitHub Pages에
바로 배포됩니다. 모든 시각화는 인라인 SVG. CI는 `node check.mjs`를 실행합니다.

## 배포 (GitHub Pages)

`main`에 푸시 후 **Settings → Pages**에서 *Deploy from a branch* → `main` / root 선택.
모든 경로가 상대경로라 서브패스에서도 그대로 동작합니다.
